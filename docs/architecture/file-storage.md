# 文件存储与本地缓存方案

## 1. 范围

本文覆盖项目照片、合同附件、回款附件、造价 Excel 及其他项目资料的本地暂存、对象存储上传、预览下载、删除恢复和容量管理。业务数据同步协议见 `sync-protocol.md`。

## 2. 设计原则

- 文件二进制保存在国内云对象存储，中央数据库只保存元数据和业务关联。
- 对象存储桶保持私有，任何用户不能使用永久公开地址访问文件。
- 文件权限继承所属项目，并由 API 在每次上传、预览和下载前校验。
- 桌面端先复制到应用管理的暂存目录，再进入上传队列。
- 本机绝对路径、用户名目录和系统凭证不得进入中央业务字段。
- 大文件支持分片、断点续传、完整性校验和失败清理。
- 文件删除先解除业务关联并进入恢复期，再物理清理。

## 3. 文件记录

### 3.1 `FileObject`

| 字段 | 说明 |
| --- | --- |
| `id` | 文件 UUID，离线可生成 |
| `projectId` | 所属项目 ID，用于授权隔离 |
| `objectKey` | 服务端生成的对象键 |
| `originalName` | 上传时原始文件名，仅用于展示 |
| `contentType` | 服务端校验后的 MIME 类型 |
| `sizeBytes` | 文件字节数 |
| `sha256` | 完整文件 SHA-256 校验值 |
| `status` | 文件状态 |
| `createdBy` | 上传用户 |
| `createdAt` | 服务器创建时间 |
| `availableAt` | 校验和安全扫描完成时间 |
| `deletedAt` | 逻辑删除时间或空 |

文件状态：

- `PENDING_UPLOAD`：已创建上传会话，内容尚未完成。
- `UPLOADING`：至少一个分片已上传。
- `VERIFYING`：分片完成，正在校验和安全检查。
- `AVAILABLE`：允许有权限用户访问。
- `QUARANTINED`：安全检查失败，禁止访问。
- `FAILED`：上传或校验确定失败。
- `DELETED`：逻辑删除，处于恢复期。

### 3.2 `FileLink`

| 字段 | 说明 |
| --- | --- |
| `id` | 关联 UUID |
| `projectId` | 所属项目 ID |
| `fileId` | 文件 ID |
| `entityType` | `PROJECT`、`CONTRACT`、`RECEIPT`、`VOUCHER`、`COST_VERSION` 等 |
| `entityId` | 业务记录 ID |
| `purpose` | 附件、原始造价文件、照片原图等用途 |
| `sortOrder` | 同一业务记录内排序 |

一个物理文件可以被同一项目内多个业务记录关联，但首期禁止跨项目共享同一 `FileObject`，避免权限变化造成信息泄露。

## 4. 对象键

对象键只能由服务端生成：

```text
{environment}/projects/{projectId}/{yyyy}/{mm}/{fileId}/original
```

派生文件使用：

```text
{environment}/projects/{projectId}/{yyyy}/{mm}/{fileId}/preview/{variant}
```

规则：

- `environment` 只能是 `dev`、`test`、`prod`。
- 对象键不包含项目名称、用户名、原始文件名或本机路径。
- 原始文件名只作为受控元数据保存，下载响应时进行安全编码。
- 各环境使用不同存储桶；即使对象键错误也不能跨环境读取。

## 5. 桌面端本地目录

每个平台使用系统应用数据目录，不允许把 SQLite 或缓存放到网络共享盘。

```text
app-data/
├── database/       # SQLite、WAL 和迁移状态
├── staging/        # 尚未完成上传的受控副本
├── cache/          # 已下载或已上传文件缓存
├── previews/       # 本地缩略图和预览
└── transfer/       # 文件任务状态，不含凭证
```

### 5.1 新文件暂存

1. 用户通过系统文件选择器选择文件。
2. 客户端检查文件可读性和基础大小限制。
3. 客户端生成 `fileId`，将文件复制到 `staging/{fileId}`。
4. 复制过程中计算 SHA-256 和字节数。
5. 本地事务写入文件元数据、业务关联草稿和上传队列。
6. 只有事务完成后界面才显示“待上传”。

原始文件随后被移动或删除，不影响暂存副本上传。暂存复制失败时不创建成功状态。

### 5.2 缓存上限

- 首期桌面文件缓存默认上限为 10GB。
- `staging` 中未完成上传的文件不参与自动淘汰，界面必须显示其占用空间。
- `cache` 超过上限时优先清理已同步、未固定且最久未访问的文件。
- 当前打开文件、用户手动固定文件和最近 7 天访问文件不自动清理。
- 用户可以手动清理已同步缓存，但不能在未确认前删除唯一的待上传副本。
- 项目权限被取消时立即清理该项目缓存和暂存业务载荷。

## 6. 上传流程

### 6.1 创建上传会话

客户端向 API 提交：项目 ID、文件 ID、原始名称、字节数、内容类型声明和 SHA-256。API 验证项目编辑权限、文件大小、扩展名策略和用户配额后创建上传会话。

服务端返回：上传会话 ID、对象键、分片大小、授权分片地址、过期时间和已完成分片。

### 6.2 单文件与分片

- 小于 16MiB 的文件可以单次上传。
- 16MiB 及以上文件使用分片上传。
- 默认分片大小由服务端返回，初始建议 8MiB，并根据对象存储限制调整。
- 客户端最多并发上传 3 个分片，避免占满办公网络。
- 每个分片失败可独立重试，不重新上传已确认分片。

### 6.3 完成确认

1. 客户端提交分片编号和对象存储返回标识。
2. 服务端完成对象合并。
3. 后台任务验证字节数和完整文件 SHA-256。
4. 文件进入安全扫描和预览生成流程。
5. 全部成功后状态变为 `AVAILABLE`。
6. 客户端再同步正式 `FileLink`，或服务端激活预先登记的关联。

对象存储的 ETag 不作为跨供应商通用的完整性校验值，权威校验值为 SHA-256。

### 6.4 失败与清理

- 会话过期后客户端重新申请授权，但沿用同一 `fileId`。
- 校验失败时对象进入隔离区，不允许下载。
- 未完成分片在 7 天后由对象存储生命周期清理。
- 服务端不得因文件上传失败回滚其他无关业务同步。
- 用户可以删除失败任务，删除前确认暂存文件是否仍是唯一副本。

## 7. 下载与预览

1. 客户端向 API 请求文件访问。
2. API 校验账号、项目读取权、文件状态和业务关联。
3. API 记录文件访问审计。
4. API 返回短时授权地址，默认有效期 5 分钟。
5. 浏览器直接预览或下载；桌面端写入受控缓存。

规则：

- `PENDING_UPLOAD`、`VERIFYING`、`QUARANTINED`、`FAILED`、`DELETED` 不返回下载授权。
- 响应头中的文件名必须转义，禁止路径穿越和响应头注入。
- 图片预览优先使用受控缩略图，原图下载仍需单独授权。
- 领导和管理员的跨项目下载必须记录审计。

## 8. 类型与大小策略

首期允许的类型由业务白名单控制：常用图片、PDF、Office 文档、Excel 和经过确认的项目资料格式。服务端同时检查扩展名、声明 MIME 和内容特征，不只信任客户端声明。

初始单文件上限建议为 2GB。超过限制的文件拒绝上传并给出明确提示；调整上限必须评估客户端磁盘、对象存储分片限制、网关超时和安全扫描能力。

## 9. 安全扫描与预览

- 上传完成文件先进入 `VERIFYING`，不能立即公开下载。
- 后台任务执行恶意文件扫描和类型校验。
- 扫描失败或类型伪装进入 `QUARANTINED`，仅安全管理员可处理。
- Office、PDF 和图片预览在隔离任务中生成，不在 API 请求进程内解析大文件。
- 预览失败不删除原文件；有权限用户仍可在安全扫描通过后下载原文件。
- 解析工具和依赖必须纳入安全更新流程。

## 10. 删除、恢复和版本保护

- 删除业务附件先逻辑删除 `FileLink`。
- 无有效关联的 `FileObject` 进入 `DELETED`，保留 30 天。
- 恢复期内有权限的项目负责人可以恢复关联。
- 30 天后后台任务物理删除对象；删除结果进入审计。
- 对象存储开启版本或误删保护，非当前版本保留至少 90 天。
- 数据库墓碑按同步协议保留 180 天，与对象物理清理分开。

## 11. 容量与生命周期

容量基线：每年新增约 200GB，三年原始文件约 600GB。规划时还需计入缩略图、对象历史版本、未完成分片和备份。

建议策略：

| 内容 | 在线保留 | 后续策略 |
| --- | --- | --- |
| 当前有效原文件 | 长期 | 保持标准或低频存储，按访问数据调整 |
| 缩略图与预览 | 随原文件 | 可重建，优先清理失败或孤立版本 |
| 未完成分片 | 7 天 | 自动清理 |
| 已删除当前对象 | 30 天恢复期 | 到期物理删除 |
| 非当前对象版本 | 至少 90 天 | 到期转归档或清理 |
| 审计中的文件元数据 | 按审计策略 | 不保留文件内容 |

每月监控：新增容量、下载流量、失败分片、孤立对象、缓存命中率和恢复期对象数量。

## 12. 备份与恢复

- 对象存储开启服务端加密和版本保护。
- 生产桶开启异地或跨区域复制，具体范围由云厂商能力和成本评估确认。
- 数据库备份必须包含 `FileObject`、`FileLink` 和对象键元数据。
- 恢复演练同时验证数据库记录与对象实际存在性。
- 每季度抽样恢复文件并核对 SHA-256，不以“备份任务成功”代替恢复验证。
- 加密密钥、访问凭证和授权地址不得写入备份说明文档。

## 13. 隐私与日志

- 普通日志不记录原始文件内容、永久访问地址、本机绝对路径或授权签名参数。
- 业务审计可记录文件 ID、项目 ID、操作类型、操作者和结果。
- 错误信息对用户显示可理解原因，对内部仅记录非敏感诊断标识。
- 可分享导出默认移除本机路径、系统同步标识和不必要的个人信息。

## 14. 故障场景

| 场景 | 预期结果 |
| --- | --- |
| 暂存复制中断 | 不创建成功任务，原文件不受影响 |
| 上传中断 | 保留已确认分片，恢复后续传 |
| 完成请求超时 | 查询上传会话状态，禁止盲目创建第二对象 |
| SHA-256 不一致 | 文件隔离，业务关联不激活 |
| 安全扫描失败 | `QUARANTINED`，普通用户无法访问 |
| 本地原文件被移动 | 已暂存任务继续上传 |
| 本地缓存被清理 | 有权限时可重新下载，不影响中央数据 |
| 权限被取消 | 停止上传下载并清理项目缓存 |
| 对象存储暂时不可用 | 业务数据同步继续，文件任务退避重试 |
| 数据库有记录但对象缺失 | 显示文件不可用并触发一致性告警 |

## 15. 验收检查

- 中央数据不包含本机绝对路径。
- 对象键不暴露项目名称、用户名或原始文件名。
- 文件上传可从任意已确认分片继续。
- SHA-256 不一致或安全检查失败的文件不可下载。
- 每次文件访问都重新校验项目权限。
- 权限撤销会清理本地文件缓存和待传载荷。
- 文件删除有 30 天恢复期，对象版本至少保护 90 天。
- 第 14 节全部场景必须在 M6 转换为自动化或集成测试。
